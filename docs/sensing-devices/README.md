## Which sensing devices can you use?

| Device                                            | Use                                | Measures                                                                                       | Connectivity              | How to get it                                        |
| ------------------------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------- | ---------------------------------------------------- |
| [SODAQ AIR](devices/sodaq-air.md)                 | Mobile and stationary              | Particulate matter, location                                                                   | SIM card (mobile network) | Bought from SODAQ in larger quantities; open design  |
| [Sensor.Community](devices/sensor-community.md)   | Stationary                         | Particulate matter, noise, temperature                                                         | Wi-Fi                     | DIY, following the community's building instructions |
| [Smart Citizen Kit](devices/smart-citizen-kit.md) | Stationary; mobile with GPS add-on | Temperature, humidity, noise, light, pressure, UV, particulate matter (optionally VOC and NOx) | Wi-Fi or micro SD card    | Bought pre-assembled or as DIY kit; open source      |
